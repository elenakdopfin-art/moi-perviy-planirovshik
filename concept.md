# Концепция проекта: личный планировщик

## Идея

Личный веб-планировщик в виде простой страницы из трех файлов: `index.html`, `style.css` и `script.js`. Приложение помогает планировать каждый день, совмещая рабочие задачи, детские занятия, домашние и личные дела, здоровье, а также дни рождения родных и знакомых.

Планировщик работает полностью в браузере: все данные сохраняются в `localStorage`, без базы данных, сервера и регистрации.

## Язык интерфейса

Интерфейс полностью на русском языке.

## Основные категории

В приложении будут категории задач:

- Работа
- Дети / занятия
- Дни рождения
- Дом
- Здоровье
- Личное

Каждая категория будет иметь свой цвет, чтобы задачи легко отличались визуально.

## Цветовая идея

Основная атмосфера интерфейса: нежная, спокойная, лиловая. Лиловый цвет используется как главный акцент, но интерфейс не должен быть однотонным.

Предварительная палитра:

- Лиловый: основная тема, кнопки, активные элементы
- Мягкий розовый: дни рождения
- Нежный голубой: детские занятия
- Мятный: здоровье
- Светлый персиковый: домашние дела
- Спокойный серо-синий или графитовый: рабочие задачи

Фон должен быть светлым, чистым и не перегруженным. Главное ощущение: легко, удобно, аккуратно, без визуального шума.

## Представления календаря

Планировщик будет иметь четыре режима просмотра:

- День
- Неделя
- Месяц
- Год

### День

Главный экран дневного просмотра — расписание по часам. Задачи с указанным временем отображаются в соответствующих временных блоках.

Задачи без времени показываются внутри календаря вверху дня, отдельным блоком над расписанием.

### Неделя

Неделя отображается в виде 7 колонок по дням. В каждой колонке видны задачи дня: сначала задачи без времени, затем задачи с временем.

### Месяц

Месяц отображается классической календарной сеткой. В ячейке каждого дня показываются задачи и дни рождения с цветовой маркировкой.

### Год

Годовой режим показывает обзор месяцев. Основная цель — быстро увидеть весь год целиком и понять, в каких месяцах больше задач, занятий и дней рождения.

## Типы задач

Задачи бывают двух типов:

- С временем
- Без привязки ко времени

Для задач с временем нужен диапазон, например `15:00-16:30`. Это подходит для встреч, звонков, занятий ребенка, врачей и других событий по расписанию.

Для задач без времени указывается только дата. Они отображаются вверху дня.

## Создание задачи

При создании задачи пользователь указывает:

- Название
- Категорию
- Дату
- Есть ли время
- Время начала и окончания, если задача привязана ко времени
- Приоритет
- Повторяемость

Дополнительно можно предусмотреть поле заметки, но оно не является обязательным для первой версии.

## Приоритеты

У задачи будет приоритет:

- Высокий
- Обычный
- Низкий

Приоритет можно показать маленькой меткой, значком или тонкой линией на карточке задачи.

## Повторяющиеся задачи

Приложение должно поддерживать повторение:

- Каждый день
- Каждую неделю
- Каждый месяц
- Каждый год
- По выбранным дням недели

Повторяемость нужна для регулярных рабочих дел, детских занятий, кружков, тренировок, домашних рутин и других повторяющихся событий.

## Дни рождения

Дни рождения добавляются как отдельная категория. Они автоматически повторяются каждый год.

Дополнительные напоминания заранее не нужны: достаточно, чтобы дни рождения были хорошо видны в календаре.

## Действия с задачами

С задачами можно:

- Создавать
- Редактировать
- Переносить на другую дату
- Удалять отменившиеся задачи

Перенос задачи выполняется через кнопку, а не перетаскиванием.

Перед удалением желательно показывать подтверждение, чтобы случайно не удалить важную задачу.

Отметка выполнения в первой версии не нужна.

## Фильтрация

В интерфейсе стоит предусмотреть фильтры по категориям:

- Все
- Работа
- Дети
- Дни рождения
- Дом
- Здоровье
- Личное

Поиск по названию задачи в первой версии не нужен.

## Хранение данных

Все данные хранятся в браузере через `localStorage`.

Пример структуры данных:

- Уникальный идентификатор задачи
- Название
- Категория
- Дата
- Время начала
- Время окончания
- Признак задачи без времени
- Приоритет
- Тип повторения
- Дни недели для повторения, если выбрано повторение по дням недели
- Дата создания

Такой формат позволит редактировать, удалять, переносить и отображать задачи в разных режимах календаря.

## Удобство интерфейса

Приложение должно быть простым и понятным:

- Быстрое переключение между днем, неделей, месяцем и годом
- Кнопка добавления задачи всегда легко доступна
- Цветные категории видны сразу
- Задачи без времени не смешиваются с расписанием по часам
- Формы не перегружены
- На экране видно только то, что нужно для планирования

Главный сценарий использования — ноутбук. Интерфейс должен быть удобным для работы с календарем на широком экране: понятные колонки, хорошо читаемое расписание по часам, быстрые кнопки управления и форма создания задачи рядом с основным рабочим пространством или в удобном модальном окне.

На телефоне приложение тоже должно открываться корректно, но дизайн в первую очередь ориентируется на использование на ноутбуке.

## Минимальный состав файлов

Проект будет состоять из трех основных файлов:

- `index.html` — структура страницы
- `style.css` — оформление и адаптивность
- `script.js` — логика календаря, задач, повторов и `localStorage`

## Первая версия приложения

В первую версию стоит включить:

- Русский интерфейс
- Четыре режима просмотра: день, неделя, месяц, год
- Создание задач
- Редактирование задач
- Удаление задач с подтверждением
- Перенос задач через кнопку
- Задачи с диапазоном времени
- Задачи без времени вверху дня
- Категории с разными цветами
- Приоритеты
- Повторяемость задач
- Автоматическое ежегодное повторение дней рождения
- Фильтры по категориям
- Сохранение данных в `localStorage`
- Удобный дизайн для ноутбука как основной сценарий

- Поиск по задачам не нужен.
- Фильтры по категориям включены.
- Подтверждение удаления включено.
